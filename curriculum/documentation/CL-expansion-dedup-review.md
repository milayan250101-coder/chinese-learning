# CL扩展课程去重与新增规划审查表

版本：1.0.0
日期：2026-11-12
审查范围：现有CL-01至CL-114及七大主题审计
状态：初步审查，尚未正式新增课程编号

## 一、审查原则

1. 保留CL-01至CL-114已经确认的编号和名称。
2. 课程名称相关不等于详细教学内容完整覆盖。
3. 能通过现有课程扩展解决的内容，不重复创建课程。
4. 需要独立教学目标、词汇体系和交际场景的主题，可以新增CL课程。
5. 系统语法讲解统一进入独立G系列。
6. 本文件中的新增建议均为候选，不代表正式课程编号。

## 九、当前审查结论

1. CL-01至CL-114保留不变。
2. 现有课程中已有明确主题的内容，优先扩展详细教学内容。
3. 缺少独立教学场景的主题进入新增课程候选。
4. 住房事务、住宿、自然环境、金融生活、社会议题等值得重点考虑。
5. G系列语法独立建设，不占用CL编号。
6. 当前判断以课程标题为依据，最终还需要结合逐课教学内容再次审查。
7. 本文件不代表新增课程数量、模块编号或正式课程编号已经确定。

## 十、下一阶段

- 对候选主题进行合并与重复检查。
- 确定每门候选课程的独立教学目标和边界。
- 评估是否需要新增模块。
- 确定CL扩展课程数量。
- 经确认后再建立正式课程目录和独立文件。
