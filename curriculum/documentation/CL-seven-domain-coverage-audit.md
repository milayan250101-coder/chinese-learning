# CL课程体系七大主题覆盖审计与扩展规划

版本：1.0.0
日期：2026-11-12
审计范围：CL-01至CL-114
目的：根据七大部分中文教学大纲，识别已有内容、部分覆盖内容、未覆盖内容及独立G系列语法内容。

## 一、审计规则

- 已覆盖：现有课程名称和教学定位已经明确覆盖该主题。
- 部分覆盖：已有相关课程，但尚未形成完整、系统的教学内容。
- 未覆盖：现有课程没有明确安排，需要新增课程或扩展专题。
- G系列语法：属于独立中文语法知识体系，不直接混入CL主题课程编号。
- 跨课程内容：可以在多个CL课程中复现和应用，不必重复建立词汇实体。

注意：本文件是课程规划审计，不代表所有主题已经完成详细教学内容。最终覆盖状态需要在逐课编写后再次核验。

# 十、后续执行原则

1. 保留已经验收的CL-01至CL-114编号与名称，不擅自改动。
2. 新主题先进入候选清单，经过重复检查和教学顺序审查后再正式编号。
3. 不把G系列语法专题直接混入CL主题课程编号。
4. 相同词汇可以在多节课程中出现，但应区分首次引入、强化和复习。
5. 语法可以在CL课程中实际运用，同时在G系列中系统解释。
6. 新增课程应考虑从初级到中高级的难度递进。
7. 每次正式新增课程时，同步更新总目录、独立课程文件和课程名称核对清单。
8. 本审计文件本身不改变现有114节课程的名称、编号或内容。

## 11.3 课程建设原则

1. CL系列负责主题、词汇、表达、情景和综合交际能力。
2. G系列负责中文语法结构的系统解释、对比、练习与运用。
3. 同一语法点可以在多节CL课程中实际使用，但系统讲解归入G系列。
4. 同一词汇可以出现在多节CL课程中，应记录其首次引入、再次出现和复习关系。
5. CL扩展候选主题不直接占用正式课程编号。
6. G系列目前只有规划分类，尚未建立正式课程文件和编号。
7. 后续应先完成重复检查、难度分级和教学顺序审查，再建立正式目录。
