# CL第二阶段课程体系规划

版本：1.0.0
日期：2026-11-12
状态：规划阶段，尚未正式建立课程编号

## 一、课程体系总体结构

Chinese Learning课程体系分为两个阶段：

### 第一阶段：CL-01至CL-114

- 共114节课程。
- 已建立10个课程模块。
- 课程名称、编号和独立文件已经完成一致性验收。
- 保留全部已确认的课程编号、名称和模块。
- 不因第二阶段扩展而重新编号或调整原有课程。

### 第二阶段：新增主题课程

- 规划从CL-115开始。
- 采用独立的主题规划与课程建设流程。
- 新增主题原则上进入第二阶段。
- 先确定主题模块、课程边界、教学目标和难度顺序。
- 完成审查并确认后，才正式分配课程编号。
- 第二阶段课程目录与第一阶段课程目录保持清晰区分。

注意：CL-115目前只是规划起点，不代表已经正式创建该课程。

### 独立G系列：中文语法体系

- G系列不属于CL第一阶段或第二阶段的主题课程编号。
- 独立规划语法知识结构、教学顺序和课程文件。
- CL课程可以在情景中使用相关语法，但不替代G系列的系统讲解。

## 二、第二阶段候选主题模块

以下均为候选方向，不代表最终模块名称和数量已经确定。

### 候选模块A：人物、家庭与社会关系

- 家庭成员与亲属关系
- 伴侣、婚姻与家庭生活
- 朋友关系与社会交往
- 人生阶段、出生、成长与个人经历

### 候选模块B：沟通交际与观点表达

- 问候、寒暄与礼貌交际
- 请求、建议、要求与回应
- 道歉、感谢、安慰与鼓励
- 个人观点、判断与理由
- 赞同、反对、讨论与协商
- 常用口语与习惯表达

### 候选模块C：教育与学习体系

- 学校、大学与教育体系
- 学科、课程与课堂活动
- 考试、成绩与学习评价

### 候选模块D：饮食、食材与烹饪

- 蔬菜、水果与常见食材
- 肉类、海鲜、蛋类与奶制品
- 主食、谷物与面点
- 调味品、香料与烹饪方法
- 家庭做饭与厨房操作
- 零食、甜点与饮品

### 候选模块E：住房事务与住宿

- 租房、买房与房屋合同

- 搬家、维修与物业沟通

- 酒店预订、入住与退房

### 候选模块F：自然地理与环境保护

- 植物、花草与树木
- 山川、河流与海洋
- 地理景观与自然环境
- 环境保护、污染与生态
- 能源与日常环保行为

### 候选模块G：新闻传媒与数字社会

- 新闻、报纸与媒体传播
- 网络信息与数字内容
- 社交媒体与网络交流
- 互联网服务与人工智能应用
- 信息辨别与媒体使用

### 候选模块H：金融、商业与产业

- 银行、货币与支付

- 商业、贸易与服务行业
- 农业与制造业
- 企业、产品与产业活动

### 候选模块I：社会生活与公共事务

- 社会现象与民生
- 公共管理与社会规则
- 法律常识与消费者权益
- 公共机构与社会服务
- 社会责任与公共参与

## 三、第二阶段课程建设原则

1. 不重复建立第一阶段已经具有明确教学目标的课程。
2. 第一阶段仅涉及少量相关词汇的主题，可以在第二阶段建立完整专题。
3. 不把单纯的词汇交叉误判为课程内容重复。
4. 每节新增课程必须有独立教学目标、主题词汇、核心表达和实际交际场景。
5. 根据中文学习难度和主题之间的关联安排教学顺序。
6. 可以跨模块关联词汇，但课程编号必须唯一。
7. 新课程仍然采用统一的12项课程内容结构。
8. 新增课程在正式确认前保持候选状态。

## 四、与第一阶段的关系

- 第一阶段已经存在的课程继续独立有效。
- 第二阶段可以复用第一阶段的词汇、句型和表达。
- 相同词汇可以出现在不同课程，但需要记录其首次出现和后续复现。
- 不因为第二阶段出现相近主题就删除第一阶段课程。
- 如果发现第一阶段课程确实缺少必要内容，可以补充原课程材料，但不得擅自改变已确认的课程名称和编号。

## 五、正式编号前的工作顺序

1. 完成第二阶段候选主题去重。
2. 对照CL-01至CL-114确定关联课程。
3. 明确每个候选主题的教学边界。
4. 合并重复或高度相似的候选主题。
5. 确定第二阶段模块划分。
6. 按照学习难度安排课程顺序。
7. 确定新增课程总数。
8. 经确认后从CL-115开始正式编号。
9. 建立第二阶段课程目录、模板和独立课程文件。
10. 执行完整一致性检查。
