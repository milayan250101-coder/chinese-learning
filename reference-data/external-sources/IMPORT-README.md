# External Chinese Learning Reference Materials

This directory contains external reference resources for the Chinese Learning
teacher platform.

## HSK-3.0

Source: https://github.com/krmanik/HSK-3.0

Selected resources:
- New HSK 2025 Hanzi
- New HSK 2025 Handwritten, including available temp resources
- New HSK 2021 Hanzi
- New HSK 2021 Handwritten
- BCT
- YCT
- Scripts and data

The existing platform HSK vocabulary and grammar datasets are intentionally
not replaced or duplicated by this resource selection.

## Anki-xiehanzi

Source: https://github.com/krmanik/Anki-xiehanzi

The repository is retained as a separate reference project, including its
available scripts, stroke data, templates, examples, and other source files.

## Important

These repositories remain external reference materials. Their presence here
does not mean that teacher-portal features have already integrated or
validated every dataset.

Please check the original repository licenses and attribution requirements
before redistributing or incorporating individual resources into the platform.

Some referenced audio resources may be incomplete or unavailable upstream.
The Anki-xiehanzi repository may reference a Git submodule; this checkout
preserves the repository reference and does not automatically import that
submodule's contents.
